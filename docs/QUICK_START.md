# Quick Start Guide

## Prerequisites
- Python 3.10+
- pip

## Installation

```bash
git clone <repo>
cd jarvis
pip install -r requirements.txt
```

## Running Jarvis

```bash
python main.py
```

## Example Commands

| You say | Jarvis does |
|---------|-------------|
| "Turn on the light" | Turns on light |
| "Set fan to 75%" | Sets fan speed |
| "What's the temperature?" | Shows room conditions |
| "I'm leaving" | Turns off everything |
| "I'm home" | Welcome routine |
| "Good morning" | Greeting response |

## CLI Commands

| Command | Action |
|---------|--------|
| `/status` | Show room conditions |
| `/history` | Show recent conversation |
| `/clear` | Clear history |
| `/quit` | Exit |
