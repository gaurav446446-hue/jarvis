# Example Conversations

## Morning Greeting
```
You: Good morning
Jarvis: Hello, Sir! How can I help you?
```

## Light Control
```
You: Turn on the light
Jarvis: Light turned on, Sir.

You: Turn off the light
Jarvis: Light turned off, Sir.
```

## Fan Control
```
You: Set fan to 75%
Jarvis: Fan speed set to 75%, Sir.

You: Turn off the fan
Jarvis: Fan turned off, Sir.
```

## Room Status Query
```
You: What's the temperature?
Jarvis: Room temperature is 24.0°C and humidity is 65.0%, Sir.

You: What time is it?
Jarvis: The current time is 09:30 AM, Sir.

You: Room status
Jarvis: Room is 24.0°C, 65.0% humidity. Comfort: ✓
```

## Arrival / Departure
```
You: I'm home
Jarvis: Welcome home, Sir! Light on and fan set to 50%.

You: I'm leaving
Jarvis: Goodbye, Sir! Lights off and fan off.
```

## Comfort Adjustment
```
You: It's too hot
Jarvis: Increased fan to 75% to cool things down, Sir.

You: Too cold
Jarvis: Reduced fan to 25% for more warmth, Sir.
```
